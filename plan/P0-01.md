Create the Next.js 16 app with Bun: React 19, TypeScript `strict` plus `noUncheckedIndexedAccess`, Tailwind v4 through `@tailwindcss/postcss`, `motion`, `zod`, `lucide-react`, Biome, Vitest (happy-dom, Testing Library) and Playwright (Chromium and WebKit, with axe). Keep the existing `src/app/globals.css` and `src/styles/` as they are.

`next.config.ts`: `output: "standalone"`, `poweredByHeader: false`. Biome: import sorting in the order third-party → react → `@/` → relative, and `noRestrictedImports` overrides for the layer table in ARCHITECTURE §3.

Scripts: `dev`, `build`, `start`, `typecheck`, `lint` (Biome, then `python3 scripts/check_tokens.py`, `python3 scripts/check_code_rules.py` and `python3 scripts/build_tokens.py --check`), `test` (`vitest run`), `e2e` (`playwright test`), `lab:shot` (`python3 scripts/lab_shot.py`), and `verify` (lint → typecheck → test → build). `layout.tsx` and `page.tsx` are stubs that later tasks fill in.
