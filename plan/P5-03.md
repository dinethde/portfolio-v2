The three workflows exactly as TECH_SPEC §7 lists. On pull requests, `ci.yml` checks the title and body with the same rules as the commit guard: `python3 .claude/orch.py check-pr --title "$TITLE" --body-file "$BODY_FILE"`. `check_secret_scope.py` fails if `GITHUB_TOKEN` appears outside `src/lib/github/`. `check_bundle.py` fails if client JavaScript is over 120 KB gzip. Both follow the structure of `check_tokens.py`.
