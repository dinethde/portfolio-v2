Build STATE D-75: the chart's last live pull survives container restarts and deploys.

**Worker.** `worker/contributions-store.ts` exports `handleStore(request, storage)`, which takes a small storage interface (`get(key)` / `put(key, value)`, the shape of `ctx.storage`) so it can be tested without Cloudflare. It must not import `@cloudflare/containers` or `cloudflare:workers`; the test imports it by relative path. Check `worker/` is in `tsconfig.json` `include` so typecheck covers it, and report in NOTES if it isn't. `PUT /` with a JSON body saves it under one key and answers 204; a body that isn't JSON with a `weeks` array answers 400. `GET /` answers 200 with the saved JSON, or 404 when nothing is saved. Anything else answers 405. In `worker/index.ts`, `PortfolioContainer` gets `static outboundByHost = { "contributions.internal": … }`. The handler reaches the one container instance with `getContainer(env.PORTFOLIO)` and calls an RPC method on it that runs `handleStore` against `this.ctx.storage`. The container must still reach GitHub: keep internet access on (check `enableInternet`'s default in the package).

**Next.js.** In `getContributions()`, after a live pull, `PUT` the result (without `source`) to `http://contributions.internal/`, awaited with a 1 s timeout; a failed save is logged as `[contrib]` and never changes what's returned. When GitHub fails, `GET` the same URL with the same timeout (Next's default caching under the page's 6-hour `revalidate` is fine, since the saved copy only changes after a live pull), parse it with the `Contributions` schema and return it with `source: "stored"`. Only if that fails too, return the bundled fallback as today. Add `"stored"` to the `source` enum in `map.ts`. Don't use `cache: "no-store"` or `revalidate: 0`: either makes `/` dynamic and breaks the 6-hour static page (ARCHITECTURE §1). Confirm `bun run build` still lists `/` as static (○) with a 6 h revalidate. Off Cloudflare, `contributions.internal` doesn't resolve, so local dev and tests fall through to the bundled file.

**Tests.** `contributions-store.test.ts`: save then load, 404 when empty, 400 on a bad body. `github.test.ts` (mock `fetch`): a live pull saves and returns `live`; GitHub failing with a saved copy returns `stored`; both failing returns `fallback`; a failed save still returns `live`.
