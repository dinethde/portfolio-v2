The dev-only lab at `/lab`. It returns `notFound()` in production. Each component's lab is its own file, `src/app/(dev)/lab/entries/<id>.lab.tsx`, picked up without editing a shared file, so parallel tasks never collide. `/lab?only=<id>` shows one entry.

`fixtures.ts` holds sample content and sample contribution data.

`bun run lab:shot <id>` (a Python script, standard library) starts the dev server if it isn't running and screenshots `#lab-<id>` at 390, 834 and 1440 into `tests/visual/out/`. A `data-force-state` attribute forces hover, focus and pressed styles so the lab can show every Figma state at once.
