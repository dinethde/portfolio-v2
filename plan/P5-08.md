CI's WebKit run failed axe's target-size rule and the phone menu test. The cause was the CSP's `upgrade-insecure-requests`: on `http://localhost`, WebKit upgraded the CSS and JS requests to https, which failed, so it tested an unstyled page that never hydrated. Send the directive only when `SITE_URL` is https (STATE D-79), and leave the menu and footer links as they are. This replaces the first version of this task, which grew their tap areas (D-78).
